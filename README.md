# Overview

RawMilk is a production-ready Android application that modernizes daily dairy ordering through an intuitive mobile experience.

Customers can subscribe to milk plans, place orders, manage deliveries, and receive real-time notifications, while administrators manage operations through a dedicated dashboard.

Built using **Trusted Web Activity (TWA)**, the application shares a single web codebase while delivering a native Android experience.

---

# Why Trusted Web Activity?

Instead of maintaining separate Android and Web applications, RawMilk uses **Trusted Web Activity (TWA)** to deliver a native Android experience from a single Progressive Web App.

### Benefits

- Single codebase
- Native performance
- Faster deployment
- Lower maintenance
- Real-time updates
- Seamless web-to-mobile integration
